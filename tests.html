Advanced Regex Examples

Examples of advanced regex patterns used in the application

Back-reference Pattern

\b(\w+)\s+\1\b

Finds duplicate words in descriptions

Example: "coffee coffee" → Match

Example: "coffee tea" → No match

Cents Detection

\.\d{2}\b

Finds amounts with cents

Example: "12.50" → Match

Example: "12.5" → No match

Beverage Keywords

(coffee|tea|juice|soda)

Finds beverage-related expenses

Example: "coffee with friends" → Match

Example: "lunch at cafe" → No match

Date Validation

^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$

Validates YYYY-MM-DD format

Example: "2025-10-15" → Match

Example: "2025-13-01" → No match

Amount Validation

^(0|[1-9]\d*)(\.\d{1,2})?$

Validates currency amounts

Example: "12.50" → Match

Example: "012.50" → No match

Category Validation

^[A-Za-z]+(?:[ -][A-Za-z]+)*$

Validates category names

Example: "Food & Drink" → Match

Example: "Food123" → No match
