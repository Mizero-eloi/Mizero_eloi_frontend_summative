About

The Student Finance Tracker helps you manage your expenses effectively. Track transactions, analyze spending patterns, set budgets, and gain insights into your financial habits.

Features

  • Real-time dashboard with spending statistics
  • Add, edit, and delete transactions
  • Powerful regex search with highlighting
  • Data persistence in browser storage
  • Import/Export JSON data
  • Multiple currency support
  • Monthly spending cap alerts
  • Full keyboard navigation and screen reader support

Regex Examples

  • \.\d{2}\b - Find amounts with cents
  • (coffee|tea) - Find beverage expenses
  • \b(\w+)\s+\1\b - Find duplicate words (advanced back-reference)
  • ^Food - Transactions starting with "Food"

Keyboard Navigation

  • Tab: Navigate through interactive elements
  • Enter/Space: Activate buttons and links
  • Escape: Close forms and dialogs
  • Arrow keys: Navigate within forms
